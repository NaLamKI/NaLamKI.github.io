# Roadmap

Three phases on the docs transition. Implementation follows the docs
concept dated **May 2026**.

## Phase 1 — Foundation (Month 1–2)

- Branding and domain migration
- *Welcome*, *Why AgriFoodData*, *Concepts · Architecture Overview* live
- *Quickstart* with an updated Starter Kit example
- API-Reference pipeline from OpenAPI established
- Existing content migrated and restructured

## Phase 2 — Personas (Month 3–5)

- Complete *Build Your Service* paths for **AI Services** and
  **Sensor Integration**
- *Examples* with two full case studies (GeoAI Telangana, Apple Yield)
- *Ecosystem & Community* with Submit-Your-Service workflow

## Phase 3 — Ecosystem (Month 6–12)

- Persona paths for **Data Apps** and **Frontend & Dashboards** complete
- Further case studies (ACRAT start-ups, drone-to-John-Deere, soil moisture)
- Multilingual: English + German via Docusaurus i18n
- Search optimisation and analytics
- First KPI review

## KPIs

| KPI | Target (12 months after launch) |
|-----|----------------------------------|
| Time-to-First-Service | < 30 minutes from first visit to a running local example |
| Active services in the catalogue | > 10 |
| External contributors (outside the consortium) | > 5 |
| Mean dwell time on main paths | > 3 minutes |
| Open documentation issues | < 20 open · median response < 14 days |
| Search queries with no result | < 5 % |
