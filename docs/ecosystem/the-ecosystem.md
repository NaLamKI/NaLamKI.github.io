# The Ecosystem

The platform connects five groups of actors:

- **Farmers** — own the operational data; consume services.
- **Start-ups and SMEs** — provide AI services, data apps, sensor stacks.
- **Industry** — machinery and FMIS vendors; both data sources and data sinks.
- **Public administration** — state and regional governments; both operators
  and policy stakeholders.
- **Science** — universities and research institutes; both contributors and
  consumers of the data.

The Telangana deployment is the canonical example — all five groups are
active in it. See [Case Study · GeoAI Telangana](../examples/geoai-telangana.md)
for the full picture.
