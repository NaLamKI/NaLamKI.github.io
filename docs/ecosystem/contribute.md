# How to Contribute

There are four common ways in.

## Issues

File issues on the relevant repository. For documentation issues, use
[`agrifooddata-docs`](https://github.com/NaLamKI/nalamki.github.io)
(repo move pending — see [Roadmap](./roadmap.md)).

## Pull requests

- Fork, branch, PR.
- A maintainer reviews; CI runs lint + build + link check.
- Smaller PRs land faster.

## Discussions & working groups

Four working groups meet on a regular cadence:

| WG | Cadence | Focus |
|----|---------|-------|
| Architecture & APIs | Tue · weekly | ITU/FAO contract evolution, OpenAPI revisions |
| Data sovereignty | Thu · biweekly | Clearing-house policy semantics, consent UX, Gaia-X & IDSA |
| Field operations & cases | Fri · monthly | NaLamKI consortium, Telangana programme, partner onboarding |
| Regulatory & policy | Wed · monthly | EU Data Act, FaIR Data Act, FAO touchpoints |

## Submit a service

If you have a service to add to the catalogue, follow the
[Submit Your Service](./submit-service.md) workflow.
