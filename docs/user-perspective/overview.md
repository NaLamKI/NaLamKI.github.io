# User Perspective

This section provides insights into how farmers and agricultural professionals interact with the NaLamKI platform. Understanding the user perspective is crucial for developers to create services that effectively meet the needs of end users.

## Key Topics

- [Farmers Workflow](./farmers_workflow.md): Understanding how farmers interact with the platform, from data upload to service selection
- [Results Monitor](./results_monitor.md): How farmers view and interpret the results from AI services

## User Journey

1. **Data Management**: Farmers upload and manage their agricultural data
2. **Service Selection**: Choose appropriate AI services for their needs
3. **Processing**: Submit data for analysis
4. **Results**: View and interpret the results through various visualization tools

## Visualization Types

The platform supports multiple visualization types to help farmers understand their data:
- Point features for specific locations
- Polygon features for areas
- Image widgets for visual data
- Charts for numerical data
- Heatmaps for spatial distributions

For detailed information about each aspect of the user experience, refer to the specific guides in this section.
