# Overview

Platform Architecture Overview
The following chapter provides an overview of the NaLamKI platform architecture, which is designed to facilitate seamless interactions between AI service providers and farmers. It highlights the key benefits of the architecture, including scalability, data standardization, and secure communication.

Additionally, this chapter will explain the workflow from a farmer's perspective to illustrate how the architecture supports effective service delivery. AI developers will gain insights into the various components they will interact with, including the messaging queues and S3 storage, as well as the helpers provided to standardize model outputs for clear visualization on the platform.

Through this chapter, developers will better understand the rationale behind the data structure and the overall workflow within the platform, helping them to effectively integrate their AI models.

1. [Platform and Dashboard](./farmer_workflow.md)

    This section provides an overview of the NaLamKI platform interface, describing how users interact with the dashboard to access services, visualize data, and manage service requests.

2. [Service Integration and Interaction](./dataflow.md)

    This section details the processes involved in integrating AI services with the NaLamKI platform, including service registration, authentication, and request handling. It outlines the workflow and key components, such as messaging queues.

3. [Semantics](./semantics.md)

    This section explores the semantic framework used within the NaLamKI platform, focusing on how data is structured, standardized, and interpreted across various AI services to ensure consistency and clarity in communication.
