# Welcome to AgriFoodData

AgriFoodData is an open, vendor-neutral data platform for digital agriculture.
It is the reference implementation of the **ITU/FAO reference architecture**
adopted by ITU Study Group 20 in **July 2024**.

This documentation is for **developers who want to extend the ecosystem** — by
building AI services, data apps, sensor integrations, or frontend modules.

## See it in production

AgriFoodData is deployed in the Indian state of Telangana, where the **GeoAI**
module serves satellite-based soil reports for the entire state. The same
codebase powers the German NaLamKI validation services and additional ACRAT
start-up integrations.

→ [Case Study: GeoAI Telangana](./examples/geoai-telangana.md)
