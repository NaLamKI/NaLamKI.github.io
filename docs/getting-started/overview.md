# Getting Started with NaLamKI

Welcome to the NaLamKI platform! This section will guide you through your first steps with the platform, from understanding the basics to creating your first AI service.

## What You'll Learn

- How to use the NaLamKI StarterKit to create your first AI service
- Basic concepts of the platform and its architecture
- How to test and deploy your services

## Getting Started Tutorial

The [StarterKit Tutorial](./starterkit.md) provides a hands-on introduction to creating AI services for the NaLamKI platform. Through this tutorial, you'll learn:

- How to set up your development environment
- How to create a basic AI service
- How to test your service locally
- How to understand and format your service outputs

This tutorial uses a simple green color detection example to demonstrate the core concepts. Once you've completed this tutorial, you'll be ready to create your own AI services for agricultural applications.
